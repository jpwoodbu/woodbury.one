# Mobile applications

## Unofficial Emotiva Remote

The Unofficial Emotiva Remote is available on the [Google Play
Store](https://play.google.com/store/apps/details?id=one.woodbury.emotiva_remote) and the Apple App Store.
It is a remote control for [Emotiva](https://emotiva.com/) XMC and RMC
processors.

[Privacy policy](privacy/emotiva_remote.md)

> **WARNING:** This app is **only** meant to work with Emotiva XMC and RMC
processor models.  The app **does not** work with the **Basx** model processors
or any Emotiva receivers. As of Oct 13, 2025, there are a few reports that this
app _mostly_ works with the new processor models `XMC-2+` and `RMC-1+`.

### Support

For technical support, contact apps@woodbury.one or post a message in the apps's
[thread](https://emotivalounge.proboards.com/thread/61042/publish-android-remote-control-app)
on the [Emotiva forums](https://emotivalounge.proboards.com/).

## Unofficial Oppo UDP-20X Remote

The Unofficial Oppo UDP-20X Remote is available on the [Google Play
Store](https://play.google.com/store/apps/details?id=one.woodbury.oppo_remote) and the Apple App Store.
It is a remote control for the [Oppo
UDP-203](https://www.oppodigital.com/blu-ray-udp-203/) and [Oppo
UDP-205](https://www.oppodigital.com/blu-ray-udp-205/) Blu-ray players.

[Privacy policy](privacy/oppo_remote.md)

# Web applications

## SC Timers

[SC Timers](https://sc-timers.woodbury.one) is for helping players run
[Contested Zones](https://starcitizen.tools/Contested_Zones) in [Star
Citizen](https://robertsspaceindustries.com/). There are various doors and
printers with cooldowns, and this app helps you keep track of them. If this is
the first you're hearing about this game and you're curious, please visit my
[referal
link](https://robertsspaceindustries.com/en/enlist?referral=STAR-RD6Y-42X5).

### Mobile version
This web app works great in mobile browsers and can be added to your home screen
to give it a native app look and feel. You can open the app in your mobile
browser with this QR code.

![QR code](sc-timers_qrcode.png)
